## Getting started

### Requirements

- Python 3.10 or newer
- Git
- Visual Studio Code or another Python editor (recommended)

### Clone the repository

```bash
git clone https://github.com/ismailkhosrowshiri/ai-engineering-journey.git
cd ai-engineering-journey
```

### Create a virtual environment

**Windows PowerShell**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

**macOS / Linux**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Run an exercise

For example, on Windows:

```powershell
python .\01-python-fundamentals\day-01-output-input\main.py
```

On macOS or Linux:

```bash
python3 ./01-python-fundamentals/day-01-output-input/main.py
```

Some exercises are interactive and expect input in the terminal.

The repository is intended to grow through these stages:

1. Python fundamentals and problem solving
2. Intermediate Python: object-oriented programming, modules, exceptions, typing, and testing
3. Practical Python projects and API integration
4. LLM fundamentals and model APIs
5. RAG, embeddings, and vector search
6. AI agents and tool calling
7. LangGraph and multi-agent workflows
8. Backend development, deployment, and a final portfolio project

## Engineering practices

As the projects become more advanced, I will apply:

- Consistent naming and maintainable project structure
- Virtual environments and dependency management
- Code formatting and linting with tools such as Ruff
- Automated tests with pytest
- Clear documentation for individual projects
- Environment variables for configuration; secrets must never be committed
