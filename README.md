# AI Engineering Learning Journey

A practical, project-based record of my transition from professional frontend development to Python, backend engineering, and AI engineering.

This repository documents what I learn, the exercises I complete, and the projects I build. It is a learning portfolio—not a claim that every topic or project is production-ready.

## Background

I have professional frontend experience with HTML, CSS, JavaScript, TypeScript, React, and Angular. I am now strengthening my Python skills before moving into LLM applications, retrieval-augmented generation (RAG), and AI agents.

## Getting started

### Requirements

- Python 3
- Git
- Visual Studio Code (recommended)

### Clone the repository

```bash
git clone https://github.com/ismailkhosrowshiri/lerning-ai.git
cd lerning-ai
```

### Create and activate a virtual environment (Windows PowerShell)

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### Run an exercise

For example:

```powershell
python .\01-python-fundamentals\day-01-output-input\main.py
```

Some exercises require interactive input in the terminal.
